# ThreadSanitizer suppressions for the fcastplaybin gate (tools/run-tsan.sh).
#
# GStreamer / GLib are uninstrumented nix-store builds: TSan cannot see
# their internal synchronization, so anything reported from inside them is
# untriageable noise by construction.
#
# MEASURED, and the reason the script does its own triage: these entries
# suppress almost nothing here, and that is a property of `called_from_lib`
# rather than a typo. It ignores accesses whose PC is INSIDE the named
# library, which an uninstrumented library never produces - it makes no
# access reports at all. What the run actually reports is instrumented RUST
# accesses whose happens-before edge runs through GStreamer's own locks
# (a pad's object lock, a stream lock, GLib's futex-based GMutex), and no
# suppression pattern expresses "the synchronization is invisible" without
# also hiding the crate's real races. So the file stays for the day a
# sanitized GStreamer is available (and for narrowly-scoped additions per the
# triage protocol), and the honest filter - a report with no GStreamer/GLib
# frame in either racing stack is REAL, everything else is unprovable - lives
# in tools/run-tsan.sh where it can be applied to whole reports.
called_from_lib:libgstreamer-1.0
called_from_lib:libglib-2.0
called_from_lib:libgobject-2.0
called_from_lib:libgio-2.0
race:g_type_
race:g_object_
